Internet & Web Fundamentals

The 24 core concepts behind how the web works, from networks and protocols to pages, addresses, and the tools that tie them together.

The Internet

Internet is a global network of interconnected computer networks that communicate using standard protocols such as TCP/IP.

  • ARPANET (1969): One of the earliest operational packet-switching networks and an important predecessor of today's Internet.
  • The Internet connects computers, servers, smartphones, networks, and other devices worldwide.

The World Wide Web (Web)

World Wide Web (WWW) is a collection of digital or electronic resources available via Internet. Web is a service that operates over the Internet and allows users to access interconnected web pages through hyperlinks.

  • Invented by Tim Berners-Lee in 1989.
  • The Web uses technologies such as HTML, HTTP, URLs, and web browsers.

Learn more at the W3C History of the Web.

W3C (World Wide Web Consortium)

The W3C develops and maintains standards and recommendations for the Web.

Examples include standards related to:

  1. HTML
  2. CSS
  3. Web accessibility
  4. Web architecture

Official website: https://www.w3.org/

Web Page

A web page is a single document available on the Web, usually created using HTML.

Example:

https://example.com/about.html

The About page is one web page.

Website

A website is a collection of related web pages and resources available under a common domain.

Example: https://www.example.com

A website may contain:

  • Home page
  • About page
  • Contact page
  • Services page
  • Blog pages

Home Page

The home page is generally the main or introductory page of a website.

Example: https://www.example.com/

It normally provides navigation to other important sections.

Index Page

An index page is commonly the default page served when a directory or website location is accessed.

Typical filenames include:

  • index.html
  • index.php
  • index.htm

For example, https://example.com/ may automatically load index.html.

Important: A home page and an index page are related concepts but are not necessarily identical.

Landing Page

A landing page is a web page designed for a specific purpose, often after a user clicks an advertisement, email link, or search result.

Typical goals:

  1. Register for a course
  2. Buy a product
  3. Download an application
  4. Submit a form

Web Browser

A web browser is software used to access and display web pages.

Examples:

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

A browser sends requests to web servers and renders the returned content.

Web Server

A web server is a computer/system and software that stores, processes, and delivers web resources to clients.

Common web-server software includes:

  • Apache
  • Nginx
  • Microsoft IIS

Basic communication:

Request / Response
Web Browser  →  HTTP/HTTPS Request  →  Web Server
Web Browser  ←  HTTP/HTTPS Response  ←  Web Server

Web Domain

A domain name is a human-readable name used to identify a website or Internet service.

Type Example Description
Domain Name www.example.com Easy to remember
IP Address 93.184.216.34 Numeric address of the server

Instead of remembering an IP address, users can use the domain name.

URL (Uniform Resource Locator)

A URL specifies the location of a resource and how to access it.

Example URL breakdown:

https://www.example.com:443/path/page.html?query=1#section

  • Protocol: https
  • Domain: www.example.com
  • Port: 443
  • Path: /path/page.html
  • Query: ?query=1
  • Fragment: #section

URI (Uniform Resource Identifier)

A URI is a broader concept used to identify a resource.

A URL is a type of URI.

Simple distinction:

  • URI identifies a resource
  • URL identifies a resource and provides its location/access method

HTTP (HyperText Transfer Protocol)

HTTP is the protocol used for communication between web clients and servers.

Example:

  • Browser → HTTP Request → Server
  • Browser ← HTTP Response ← Server

HTTP commonly uses port 80.

HTTPS (HyperText Transfer Protocol Secure)

HTTPS is HTTP communication protected using modern cryptographic security, primarily through TLS.

It provides:

  1. Encryption
  2. Authentication
  3. Data integrity

HTTPS commonly uses port 443.

SSL (Secure Sockets Layer)

SSL was an earlier security protocol designed to secure network communication.

Important: SSL has been deprecated and replaced by TLS. Modern HTTPS uses TLS, not SSL.

TLS (Transport Layer Security)

TLS is the modern cryptographic protocol used to secure communications such as HTTPS.

A simplified model:

TLS Handshake
Client  →  TLS Handshake  →  Server
Client  ←  Encrypted Data  ←  Server

HTML (HyperText Markup Language)

HTML is the standard markup language used to structure web pages.

Basic Structure of a web page (boilerplate):

index.html
<!DOCTYPE html>
<html>
<head>
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta charset="utf-8">
    <title>Web Page</title>
</head>
<body>
    
</body>
</html>

See also: MDN HTML Documentation

IP Address

An IP address is a unique numeric address that identifies a device on the internet or a local network.

Version Example Format
IPv4 192.168.1.10 32-bit dotted decimal
IPv6 2001:db8::1 128-bit hexadecimal

A domain name is translated into an IP address so that network communication can take place.

DNS (Domain Name System)

DNS translates human-readable domain names into IP addresses and performs other naming functions.

Example:

www.example.com → DNS → 93.184.216.34

NSlookup / nslookup

nslookup is a command-line tool used to query DNS information.

Example:

Terminal
nslookup example.com

It can help determine:

  • IP addresses associated with domains
  • DNS server information
  • DNS records

Search Engines

A search engine is a service that helps users find information and web pages on the Internet.

Examples:

  • Google
  • Bing
  • DuckDuckGo

Basic process:

  1. User enters query
  2. Search Engine
  3. Search Index
  4. Relevant Results
  5. User selects a result

ChatGPT

ChatGPT is an AI-based conversational system developed by OpenAI. It can understand natural-language prompts and generate responses, explanations, summaries, code, and other content.

Important distinction:

A search engine primarily helps users find existing information, while ChatGPT primarily generates responses based on its model and available information/tools.

Visit: https://chat.openai.com

Hyperlinks / Links

A hyperlink is a clickable reference that connects one resource to another.

HTML example:

Example
<a href="https://example.com">Visit Example</a>

Links can connect:

  • One web page to another
  • One section to another (e.g., Back to top)
  • A website to another website
  • A page to a file or resource
